Before you begin · requirements and an example

Is this a suitable task?

A meaningful scientific question; decisions for the AI to make; accessible resources and clear evaluation; reliable materials with permission to use them. Read current task examples and the proposal board below before starting.

Contributor details are entered once and reused for your next local proposal. Account sign-in and shared permissions will be connected with the server.

Illustrative proposal: formulation search

Scientific purpose: assess whether the AI improves a formulation through experiments. Decisions: choose the next mixture. Feedback: measured colour after each round. Evaluation: final error, experiment budget and decision record.

The complete task would add actual starting inputs, allowed mixtures, feedback fields, output format, an evaluation rule and the operating protocol. This example explains the form; it is not a submitted task or a required task category.

What makes a useful AISLE contribution?

A scientific decision loop

Explain the scientific purpose, what the AI can decide, what feedback it receives, and how success is evaluated. Existing task categories are examples, not a restriction on new contributions.

A proposal first, a runnable task later

A short explanation and an illustrative example are enough to discuss a proposal. Before full task review, provide actual inputs or an access plan, allowed actions, feedback, output requirements and evaluation criteria. A unique reference answer is not required when a clear judgment rule is available.

Materials reviewers can inspect

Include protocols, resource requirements, provenance and usage rights. Separate material intended for participants from reviewer-only references and hidden scoring information. Wet-lab tasks should explain who operates the experiment and how observations become AI feedback.

After acceptance

An accepted task waits for integration. Running experiments, returning measurements and connecting the experimental database are a later step.
